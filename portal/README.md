# HUDHUD CONTROL — بوابة المنظومة الموحدة

بوابة الإدارة المركزية لمنظومة HUDHUD. هذه البوابة **جديدة بالكامل** ولا تمس أيًا من التطبيقات السبعة القائمة.

## الوضع الحالي (المرحلة 1)

- سجل تطبيقات موحد (`src/lib/registry.ts`) بالأسماء الرسمية والمعرّفات التقنية دون تغيير.
- فحص صحة فعلي لكل تطبيق عبر متغيرات البيئة (`HUDHUD_APP_*_URL`) مع حماية SSRF ومهلة 5 ثوانٍ — النتائج حقيقية لحظية وليست وهمية.
- صفحة لوحة قيادة RTL بالهوية الموحدة (داكن + ذهبي `#F5A623` + IBM Plex Sans Arabic).
- حالات صريحة: يعمل / يعمل جزئيًا / غير متاح / **غير معروف** (عند غياب عنوان التشغيل — لا يُدّعى صحة غير مثبتة).

## التشغيل

```bash
cd portal
npm install
HUDHUD_APP_NEWS_URL=http://localhost:3001 npm run dev
```

## القواعد

- التنقل المباشر إلى التطبيقات؛ لا iframes افتراضيًا.
- البوابة ليست اعتمادًا تشغيليًا لأي تطبيق؛ تعطلها لا يعطل المنظومة.
- لا وصول مباشر لقواعد بيانات التطبيقات؛ التكامل عبر APIs موثقة فقط.
