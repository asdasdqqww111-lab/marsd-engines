## 4. Backup/Restore (إجراء موثق قابل للتشغيل)

> يعمل على PostgreSQL فقط (كل التطبيقات ذات بيانات). loki يستخدم تخزينه المعزول (SQLite WAL — نسخه نسخ ملف).

```bash
# نسخ احتياطي (من خادم staging):
pg_dump --format=custom --no-owner --no-privileges "$DATABASE_URL" > hudhud_staging_$(date -u +%Y%m%dT%H%M%SZ).dump
sha256sum hudhud_staging_*.dump > hudhud_staging_$(date -u +%Y%m%dT%H%M%SZ).sha256

# استعادة (في قاعدة نظيفة بنفس الإصدار):
createdb hudhud_restore_test
pg_restore --no-owner --dbname hudhud_restore_test hudhud_staging_<TS>.dump
# التحقق: عينات جداول أفضل-auth في zexا (user/session/account) تعود
# وعدادات لوحة zexa-admin تظهر أرقامًا مطابقة لما قبل النسخة.
# loki: انسخ مجلد تخزين النتائج المعزول (مسار result_store) — ملف مسطح.
```

**معيار نجاح البند:** نسخة تُنشأ، وتُستعاد في قاعدة اختبار، والبيانات الحرجة (مستخدمو zexa، نتائج loki) تُقرأ بعد الاستعادة — موثقة بلقطة/سجل تشغيل. **NOT RUN حتى التنفيذ.**
